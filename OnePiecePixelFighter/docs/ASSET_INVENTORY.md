Each fighter's assets live in its own folder:

```
src/ReplicatedStorage/Characters/<Id>/
    CharacterConfig.luau   stats, style, description, VFX theme, every move's frame data
    FrameData.luau         (generated) per-frame timelines, hurtboxes, hitboxes, VFX anchors
    Sprites/               (generated, client only)
        init.luau          palette, alternate palette (mirror matches), portrait
        Idle  Walk  Jump  Attacks  Specials  Hit  Victory   (large sheets split into _1, _2 ...)
art/Characters/<Id>/       the same sheets as PNG + JSON (cell size + origin) for editing
art/previews/<Id>.png      every animation, hurtboxes blue, hitboxes red
```

The `CharacterData` tests check that no two fighters share frame data, and that every frame referenced by an animation exists in that fighter's own sheet.

Attack frames are tagged **startup / active / recovery**. The game maps each move's frame data onto those phases, so the strike pose is on screen exactly while the hitbox is live. A test checks this for every move of every fighter.

## How a frame is made

1. **Pose:** joint angles, IK foot/hand targets, weapon angles, expression, squash. Feet stay planted through IK, so characters do not slide.
2. **Rasterise at 1×:** tapered capsules (limbs), ellipses (heads, muscles) and polygons (clothes, hair, coats) are cel-shaded from one fixed upper-front light into 3–5 tone hue-shifted ramps. There is no anti-aliasing, blur or scaling.
3. **Line art:** a dark line wherever a part overlaps a part behind it, plus a 1 px outline around the silhouette.
4. **Face stamps:** hand-placed pixel patterns for each expression (neutral, angry, shout, grin, hurt, KO; Gear 5's laugh, Doflamingo's shades).
5. **Data:** the frame is trimmed and deduplicated, then the tool records hurtboxes from the skeleton and hitboxes from the striking limb or blade on active frames. It also records anchors (hands, feet, head, blade tips, staff tip, trident tip) used for VFX such as sword trails.

Origins are always the point between the feet, so frames never jump around and ground contact is consistent.
